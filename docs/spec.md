# 第一版确认规格

当前优先完成自己的 macOS Safari 扩展，暂停 Chrome 联调与交付。点击扩展图标打开独立图片库，复用已打开的图片库标签页。

## grid 图库确认规格

- 首次进入显示 grid 图库，之后记住上次视图；旧版查看状态没有布局字段时默认进入 grid 图库。
- 保留原始比例的瀑布流，小 / 中 / 大三种尺寸，默认中；窗口自适应列数，不改变缓存或原图质量。
- 全部图片 / 收藏 / 隐藏筛选与大图视图共用数据和筛选范围。每个栏目独立持久保存 grid 图库和侧栏的 ID 锚点与相对偏移；切换尺寸沿用图片锚点，不为每档尺寸额外保存一套位置。
- 点击图片进入现有大图视图，返回按钮或 Esc 回到 grid 图库并恢复位置。大图方向键在当前筛选范围内切图。
- 卡片以图片为主，悬停或键盘聚焦时显示标题和收藏按钮；已收藏标记始终可见。
- grid 图库与左侧列表使用虚拟化，只挂载可见区域及少量预加载区域；离开范围后卸载卡片，最近使用的已解码缩略图保留在共享内存缓存中。内存预算 256 MB，包含图像字节和解码像素估算，不重新引入磁盘容量限制。滚动可见范围通过列内二分查询计算，不逐帧遍历全部历史记录。刷新、切换尺寸和改变窗口宽度保留当前图片定位。
- 本地缩略图直接只读访问 IndexedDB，绕过后台消息和 base64 转换。缓存读取、缩略图下载与邻图原图预载分开；屏幕内图片优先，附近区域只预读本地资源，过期任务跳过。回滚与视图切换复用已解码图片元素。
- 原图已缓存时，缩略图按实际显示尺寸和屏幕像素密度生成，切换尺寸时补足分辨率，不放大低分辨率预览来替代已有原图。旧缩略图按需重建并保存。Safari 不透明图片使用原生高质量 JPEG，透明图片保持 PNG 与透明通道；原图保持不变。图片尺寸保存并在后续刷新保留。
- 性能验收目标为最近看过的缩略图回滚后 1–2 帧显示，首次进入正常已有缓存区域约 200 ms 内显示。必须记录真实 Safari 的像素显示耗时；旧缓存首次重建与网络未缓存图片单独统计，不能用卡片挂载数量代替加载耗时。
- grid 图库底部和大图视图左侧显示缓存进度条、已缓存原图 / 官网总数（含隐藏）与当前阶段。历史扫描期间说明总数仍在增加，不能误报全部完成；暂停或失败状态明确可见。

- 以官方 `/images` 收录的图片为准，先显示最近图片，后台逐步加载历史图片并显示进度。
- 模仿 ChatGPT 风格，支持系统深浅色，左侧缩略图、右侧大图。
- 大图优先占用屏幕：180 px 缩略图栏可一键收起，工具悬浮，闲置 2.2 秒后淡出，不预留顶部或底部工具栏空间；默认完整适应可用区域并允许放大超过原始尺寸。
- 图片库可见时每 30 秒刷新，切回时立即检查，提供手动刷新。新增图片加入顶部，保持当前图片、缩放、平移与缩略图的可见位置。
- 「按需缓存 / 全量缓存」两种模式，默认全量。全量补齐官网所有可枚举图片及新增图片，含隐藏；按需在 grid 图片实际可见约 300 ms 后下载原图。屏幕外预加载和快速掠过不入队，入队后保留，新可见优先。
- 模式只决定下载时机，原图不按时间、切换模式、取消收藏或来源删除自动清理。前后各两张仍可预加载。暂停后台缓存不阻止主动打开大图；全量切到按需停止后续全量任务并保留按需任务。
- 左侧底部一行显示缓存进度，设置中显示模式、缓存和收藏占用、暂停、继续、失败重试与迁移状态。保存失败保留已经完成的缓存；空间不足时暂停，用户重试后继续。
- 关闭图片库后继续尝试后台缓存。逐页扫描进度与已完成图片保存在本地；后台被卸载后恢复游标，已完成图片不重复下载，中断的单张图片重新下载。Safari 完全退出时暂停，下次运行恢复；后台运行不保证持续不断。
- 收藏保存在 App 持久目录，F 收藏或取消收藏，全部图片 / 收藏切换；收藏原图单独保留，不受普通缓存清理影响。显示占用空间，保存失败时保留收藏标记并提示。取消收藏后回到普通缓存。
- 左右箭头切图，列表两端停止；主动切图重新适应窗口。0 适应窗口，1 原始尺寸。触控板捏合缩放；放大后双指滚动或鼠标拖拽平移。
- 重新打开恢复当前图片、过滤范围、缩略图滚动、缩放和平移；首次打开显示最新图片。
- 使用 Safari 的 ChatGPT 登录状态，不另设账号。退出后停止更新，但本地缓存和收藏可查看；不同账号隔离，不做跨浏览器同步。
- 官网消失后，已缓存原图仍可查看并标记「来源已删除」，收藏和隐藏照常有效；未保存原图且未收藏的记录不显示。已缓存的本地保留原图单独统计，不计入官网缓存分母。刷新失败保留现状；单张加载失败可重试并切图。
- 提供下载，能够取得对应链接时提供打开原聊天，原聊天在另一个标签页打开。

## 数据访问

扩展通过 Safari 的 ChatGPT 页面访问图片库。不保存登录令牌，不传到扩展之外，不使用独立服务器。没有可用的 ChatGPT 页面时，自动打开后台图片库标签页完成连接；未登录时暂停下载并提示用户登录。

ChatGPT 的图片库接口不属于公开稳定 API。接口、分页和原图路径必须通过真实账号验证；无法识别数据结构、分页停止前进或请求失败时，保留已有数据，不把失败当作官方删除。

2026-10-07 已核实官方网站使用 `/backend-api/my/recent/image_gen`，首屏 `limit=25`，后续 `limit=20&after=<cursor>`；排除 `is_archived` 项，游标为空才到达结尾。该行为来自网站实际发布的静态模块，后续仍可能变化。

## 额外的明确行为

切换全部图片 / 收藏时保留当前大图，下一次点击缩略图或按方向键时才切换。缩略图按图片创建时间倒序排列。当前图片不可用或已移出列表时，仍可以用方向键转到列表中的图片。

## v0.3.0 隐藏、定位与 prompt

- 隐藏功能仅保存账号隔离的 ID，不创建或固定图片副本，不改变缓存模式与收藏规则。刷新、重开、来源删除后仍保留隐藏 ID；来源不存在且未保存原图、未收藏的图片不显示，重新出现后仍隐藏。
- 隐藏图片只在「隐藏」栏目显示，全部图片、收藏、普通侧栏、方向键和相邻原图预取都排除隐藏图片。切换栏目不会把隐藏的大图留在普通视图，也不会把普通大图留在隐藏视图。
- 隐藏当前大图或取消隐藏当前隐藏大图后，立即选下一张；没有下一张取上一张，列表为空则清空查看器。收藏状态独立保留。
- 卡片和大图提供隐藏 / 取消隐藏。布局动画约 200 ms，消失卡片淡出缩小，已挂载卡片平滑移动，保留附近锚点；不为整库挂载 DOM，不逐帧重新计算瀑布流，连续操作取消并接续，减少动态效果时关闭动画。
- 收藏中的卡片和大图提供「在全部图片中定位」，切到全部图片的 grid 图库并对齐目标图片，保留收藏位置。隐藏栏目不提供该按钮。来源已删除但已保存原图的收藏仍可在全部图片中定位。
- 大图提供「复制 prompt」，指当次生成 / 修改的用户原文。按稳定图片标识和消息所在父链匹配，不按最新分支、时间或标题猜测。修改图复制修改指令，重新生成和同次多图共享原请求；不自动拼接前文或参考图片。
- 仅按需请求对应聊天，只返回匹配原文；会话内缓存最多 200 个结果，不持久保存 prompt 或整段聊天。匹配失败明确提示打开原聊天。复制在点击内发起，等待异步文本；浏览器拒绝写入时可再次点击重试，API 不可用时手动复制。
- GitHub 公开仓库为 `grepug/chatgpt-images-manager-extension`，MIT 许可证。只发布源码、测试和通用文档，不发布生成项目、依赖、安装包、真实图片或私人图库数量。

## v0.4.0 Describe edits 与 Toast

- Toast 相对整个窗口水平居中，随文字收缩，最多 420 px，窄窗口限制为窗口宽度减 40 px，长文字换行。
- 大图底部提供「Describe edits」，默认约 480 × 48 px，窄窗口缩小，多行最多约 88 px 文本高度。悬浮而不压缩图片，沿用闲置 2.2 秒隐藏；聚焦、悬停时保持可见。缩放控件在顶部，标题背景随内容收缩。
- Enter 提交，Shift+Enter 换行，输入法组合时不提交。草稿按账号与图片 ID 分别在当前会话内保留，切换图片不串稿，刷新保留输入，不将草稿写入数据库。
- 提交打开独立 Safari 窗口，重新核对账号，精确读取原聊天中的生成图片。通过官网服务创建新编辑会话，携带原图文件与生成标识、用户编辑指令，由官网处理生成与结果导航。原聊天保持不变。
- 缺少原图身份、源图片已删除、账号变化、原图匹配不唯一或官网接口未就绪时不发送编辑。失败保留草稿；提交进行时阻止重复操作，已尝试提交但结果不确定时不自动重试。
- 新增 `scripting` API 权限，网站权限仍只包含 ChatGPT。官网执行环境只接收账号校验摘要、原图标识、编辑指令和任务 ID，凭据留在官网。

## v0.5.0 原生存储与缓存模式

- 原图、索引、收藏、隐藏 ID 与进度位于共享容器的 Application Support。Safari profile 和 ChatGPT 账号隔离；原生层从原图生成清晰缩略图，使用原生 Caches 和 Safari IndexedDB 作为可重建缓存，分块传输缩略图以避免发送完整原图。解码内存预算 256 MB。
- 固定同一团队签名，先验证共享容器、原生通信、App 关闭读取与滚动性能，通过后复制真实数据。每张原图校验大小与 SHA-256；重复分块、重复提交可安全重试。
- 同一签名身份直接复制；跨签名身份用只读旧存储导出工具及新 App 的目录选择器导入，不将空的新库视作旧库迁移成功。
- 复制支持续传，失败不清理。核对完成后显示手动清理旧存储入口；跨签名版本先提供核对凭据，用户在旧工具执行清理。旧图库索引、收藏、隐藏和导出副本保留。
- 按完整原图统计已缓存数量，总数包含隐藏；扫描未结束显示总数仍在增加，失败不称完成。按需模式不将未浏览图片列为待缓存。官网消失的本地原图单列本地保留数量。
- 本次只做本地；Safari 退出暂停下载，重开续传，App 窗口可以关闭；空间不足暂停且不自动删除原图。
