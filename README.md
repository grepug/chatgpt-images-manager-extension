# ChatGPT Images Manager

macOS Safari 扩展。点击 Safari 工具栏图标打开独立图片库，支持 grid 图库、大图视图、左侧缩略图、快捷切图、触控板缩放、本地收藏、隐藏图片、复制 prompt 和自动缓存。源码以 MIT 许可证公开。

当前只交付和联调 Safari。共用 WebExtension 源码保留，Chrome 联调暂停。

## 使用

1. 运行 `build/DerivedData/Build/Products/Debug/ChatGPT Images Manager.app`，让 Safari 注册扩展。
2. 在 Safari → Settings → Extensions 启用 ChatGPT Images Manager，允许访问 `chatgpt.com`。
3. 在 Safari 登录 ChatGPT，点击扩展工具栏图标打开图片库。
4. 左侧底部的「缓存设置」可选择 1 周 / 1 个月 / 半年，默认半年。范围仅影响原图、缩略图的自动缓存与清理，全部历史图片仍可浏览。收藏独立保留。

本地开发构建使用 ad-hoc 签名，需要开启 Safari → Settings → Developer → Allow unsigned extensions。该设置会在退出 Safari 后重置；重新启动 Safari 后可能需要再次启用。正式分发需要有效签名与相应分发流程。

| 操作 | 快捷键或手势 |
| --- | --- |
| 上一张 / 下一张 | ← / → |
| 收藏 / 取消收藏 | F |
| 适应窗口 | 0 |
| 原始尺寸 | 1 |
| 缩放 | 触控板捏合 |
| 平移 | 双指滚动或鼠标拖拽 |

图片库重新打开后恢复当前图片、过滤范围、缩略图位置、缩放和平移。浏览时每 30 秒刷新，切回图片库时立即刷新，刷新保留当前查看状态。

## grid 图库

首次进入显示 grid 图库，此后记住上次使用的视图。图片按原比例排成瀑布流，提供「小 / 中 / 大」三种尺寸，默认「中」；尺寸仅改变显示密度，不改变缓存范围或原图质量。顶部可切换「全部图片 / 收藏 / 隐藏」，每个栏目分别保存 grid 图库和侧栏的滚动位置，重新打开后恢复。

点击图片进入现有大图视图，点击「返回 grid 图库」或按 Esc 返回，并恢复浏览位置。卡片悬停或键盘聚焦时显示标题和收藏按钮；已收藏标记始终可见。卡片获得焦点时用方向键移动、Enter 打开、F 收藏或取消收藏。

卡片悬停或键盘聚焦时可以隐藏图片，大图工具栏也提供相同操作。隐藏状态只保存按账号隔离的图片 ID，不复制图片、不额外固定缓存；已有时间缓存与收藏规则继续生效。隐藏图片仅在「隐藏」中显示，隐藏的收藏不会出现在「收藏」，取消隐藏后仍保留收藏状态。在正常大图视图中隐藏当前图片，会立即切到相邻可见图片；最后一张移除后显示空状态。隐藏与取消隐藏使用约 200 ms 的淡出和布局移动动画，只处理已挂载卡片，并尊重系统减少动态效果设置。

收藏卡片和收藏的大图工具栏提供「在全部图片中定位」：切到全部图片的 grid 图库并滚动至该图片，同时保留收藏的原浏览位置。隐藏栏目不提供定位按钮；已从 ChatGPT 删除的收藏也无法在全部图片中定位。

大图工具栏的「复制 prompt」按需读取原聊天，匹配该图片生成消息所在分支最近的用户原文。修改图片复制当次修改指令，重新生成复制原请求；同次生成的多张图片共享用户原文，不包含参考图片或整个聊天上下文。匹配失败时提示打开原聊天，不复制图片标题或其他分支的文字。只在当前图片库会话内缓存匹配文本，不将 prompt 或整段聊天写入本地数据库。Safari 一次点击可等待聊天请求后复制；浏览器拒绝复制时提示重试，API 不可用时提供可选文字手动复制。

grid 图库和左侧缩略图列表均只挂载屏幕附近的卡片。最近看过的缩略图保留在共享内存缓存中，回滚和从大图返回时直接复用已解码的图片元素；内存预算为 256 MB，按图片字节和解码像素估算，优先回收较久未用的资源。这个预算不限制磁盘缓存。

本地缓存直接读取，和联网下载分开调度；屏幕内图片优先，附近区域只预读本地图片。原图已缓存时，缩略图根据显示尺寸和屏幕像素密度生成，小 / 中 / 大切换会补足所需像素。旧的模糊或过大的缩略图自动从本地原图重建，不透明图片采用高质量 JPEG，透明图片保留 PNG；原图不改动。已知图片尺寸会保存，减少首次显示时的瀑布流重排。切换尺寸、刷新新增图片和窗口宽度变化时保留浏览定位。

## 自动缓存

默认自动缓存最近半年的原图和缩略图，没有应用层容量上限。1 周按 7 天计算，1 个月和半年按当前时间往前 1 个和 6 个日历月计算。超过范围的普通缓存自动清理；正在查看的图片保留至切换或关闭，收藏独立保留。下载由新到旧，历史列表扫描和下载进度自动保存。

关闭图片库后，后台继续尝试缓存；Safari 可以暂停扩展后台，所以不能保证一直下载。每分钟的后台唤醒、重新打开图片库或 Safari 启动会尝试恢复。已完成图片会跳过，中断的单张图片重新下载。Safari 完全退出后不下载。没有来源页面时自动打开后台 ChatGPT 图片库页；退出 ChatGPT 后暂停联网操作，缓存仍可查看。

grid 图库底部和大图视图左侧显示缓存进度条、已缓存 / 已找到范围内图片数量和待缓存数量，区分正在缓存原图、缩略图、查找历史图片、暂停和等待重试。历史扫描尚未结束时显示「总数仍在增加」，进度条保持不确定状态；成功结束扫描后才显示确定百分比。设置同时显示进度、空间占用及失败项。单张失败不会阻塞其他图片；未完成项目自动退避重试。空间不足时暂停并保留已保存的图片，腾出空间后可点击「重试未完成的缓存」。取消收藏后，该图片重新遵循普通缓存的时间范围。

## 开发与构建

需要 Node.js、Xcode 和 XcodeBuildMCP CLI。依赖用于打包与测试，扩展运行不依赖第三方服务。

```sh
rtk proxy npm ci
rtk proxy npm run check
rtk proxy npm test
rtk proxy npm run safari
rtk proxy npm run safari:run
```

`safari` 使用 Xcode 自带转换器生成 macOS 包装项目，并将后台模块打包为 Safari 可用的经典脚本。`safari:run` 通过 XcodeBuildMCP CLI 构建并运行；长 JSON 参数先写入 `/tmp` 文件。不要修改 `build/` 中的生成文件，修改 `extension/` 或构建脚本后重新生成。

```sh
rtk proxy npm run preview
```

本地预览地址为 `http://127.0.0.1:4173/library.html?preview=1`，只使用测试图片，不连接真实账号。预览模式不会在扩展 origin 中启用。

## 数据与验证

图片、收藏、时间范围、进度和查看状态保存在本机 Safari 扩展存储中，账号隔离。登录凭据仅在 ChatGPT 页面的隔离脚本中短暂使用，不写入图片缓存，不发送到其他服务。扩展网站权限只包含 `https://chatgpt.com/*`。

ChatGPT 的网站接口不是公开稳定 API；数据结构或分页异常时保留原有记录，不把失败误判为图片删除。当前实现按网站实际发布模块中的 `after` 游标分页。自动化测试覆盖缓存时间边界、收藏保护、状态隔离、队列恢复、重复分页、空间不足与并发收藏。真实 Safari 验证结果见 `docs/verification.md`。
