# ChatGPT Images Manager

macOS Safari 扩展。点击 Safari 工具栏图标打开独立图片库，支持 grid 图库、组合筛选和 View、大图视图、左侧缩略图、快捷切图、触控板缩放、本地收藏、隐藏图片、归档所在聊天、复制 prompt、Describe edits 和自动缓存。源码以 MIT 许可证公开。

当前只交付和联调 Safari。共用 WebExtension 源码保留，Chrome 联调暂停。

## 使用

1. 运行 `build/NativeDerivedData/Build/Products/Debug/ChatGPT Images Manager.app`，让 Safari 注册扩展。
2. 在 Safari → Settings → Extensions 启用 ChatGPT Images Manager，允许访问 `chatgpt.com`。
3. 在 Safari 登录 ChatGPT，点击扩展工具栏图标打开图片库。
4. 「缓存设置」提供「按需缓存 / 全量缓存」，默认全量缓存。已保存原图持续保留，模式切换不删除图片；设置中可以暂停、继续和重试。

本地开发构建使用固定 Apple Development 身份和团队，App 与扩展共享持久容器。此开发构建仍可能需要开启 Safari → Settings → Developer → Allow unsigned extensions。该设置会在退出 Safari 后重置；重新启动 Safari 后可能需要再次启用。正式分发需要有效签名与相应分发流程。

| 操作 | 快捷键或手势 |
| --- | --- |
| 上一张 / 下一张 | ← / → |
| 收藏 / 取消收藏 | F |
| 适应窗口 | 0 |
| 原始尺寸 | 1 |
| 缩放 | 触控板捏合 |
| 平移 | 双指滚动或鼠标拖拽 |

图片库重新打开后恢复当前图片、过滤范围、缩略图位置、缩放和平移。浏览时每 30 秒刷新，切回图片库时立即刷新，刷新保留当前查看状态。

## grid 图库

grid 顶栏的「筛选」通过二级菜单添加生成日期、宽高比例、横图 / 竖图 / 方图和聊天归档状态。整组选择「满足全部条件 / 满足任一条件」，不混用且 / 或、不嵌套；全部图片 / 收藏 / 隐藏仍是外层栏目，或条件不会绕过隐藏规则。有效条件立即生效，尚未填完或无效的值不改变当前结果；可以逐条修改、删除或清除。

日期按系统时区解释，支持某年 / 月 / 日、包含起止日的区间，以及早于 / 晚于和不早于 / 不晚于。今天、最近 7 / 30 天、本月、今年随本地日历更新，最近 N 天包含今天共 N 天。比例提供预设和自定义宽:高，精确匹配或允许 2% 相对误差的接近匹配，不提供 px 条件。缺失信息可用日期未知 / 尺寸未知查找；尺寸筛选先从现有缩略图属性和 App 已缓存原图属性分批补齐，不额外下载原图、不生成缩略图。

「View」保存当前栏目、条件和全部 / 任一规则，按账户保存在 App。支持搜索切换、重命名、复制和删除；View 是动态规则，新图片满足条件就会进入结果。修改已保存 View 时标记已修改，明确更新、另存或恢复，避免自动覆盖；重复名称会提示。手动切换栏目退出 View，并保留条件作为临时筛选。每个 View 保存自己的滚动位置，第一次从顶部开始；临时条件变化保留仍存在的图片锚点，否则回到顶部。

筛选入口仅在 grid 中提供；打开大图后，缩略图和上一张 / 下一张沿用同一结果，返回时恢复 grid 状态。主动切换 View、栏目或修改条件退出多选并清空选择；后台刷新只剔除不再属于结果的选择，全选与批量操作只作用于筛选结果。旧归档筛选和位置会迁移到组合筛选。

首次进入显示 grid 图库，此后记住上次使用的视图。图片按原比例排成瀑布流，提供「小 / 中 / 大」三种尺寸，默认「中」；尺寸仅改变显示密度，不改变缓存模式或原图质量。顶部可切换「全部图片 / 收藏 / 隐藏」，每个栏目分别保存 grid 图库和侧栏的滚动位置，重新打开后恢复。

点击图片进入现有大图视图，点击「返回 grid 图库」或按 Esc 返回，并恢复浏览位置。卡片悬停或键盘聚焦时显示标题和收藏按钮；已收藏标记始终可见。卡片获得焦点时用方向键移动、Enter 打开、F 收藏或取消收藏。

顶栏「多选图片」进入多选：点击卡片或对聚焦卡片按 Enter / Space 切换选择，Shift 点击连续选择，Cmd+A 全选当前栏目（含屏幕外图片）。滚动和小 / 中 / 大切换保留选择；切换栏目退出并清空，刷新仅保留仍属于当前栏目的图片。选择只保存在当前页面会话中。

多选顶栏提供已选数量、全选、清空、隐藏、收藏和完成；窄窗口把部分操作收进同款菜单，顶栏高度保持稳定。隐藏栏目改为取消隐藏；收藏将所选图片设为收藏，不反转已有收藏，全部已收藏时按钮禁用。菜单提供取消收藏，保留原图。F 批量收藏，Esc 退出并清空；菜单和输入框内的快捷键仍只操作自身。

批量标记每次保存 50 张，并显示进度；处理时可以滚动，选择和栏目切换暂时锁定。「停止」只停止后续批次，不撤销已完成保存。成功图片移出选择，失败和未处理图片继续选中，Toast 直接显示结果，可再次操作重试。原图下载与标记保存分开，按既有缓存设置在后台继续。完成后统一使用原有淡出和瀑布流布局动画，遵守减少动态效果设置；选择描边和顶栏切换也有轻量过渡。

图片卡片和左侧缩略图用紧凑图标表示聊天未归档或归档状态未能确认，悬停显示完整说明；聊天已归档时不显示标记，图片仍保留。大图详情和无障碍标签保留完整状态。顶部筛选可与全部图片、收藏、隐藏组合使用；每种组合保留自己的滚动位置。状态读取优先处理当前图片和可见卡片，每次最多读取 10 个聊天，后台逐步补齐，状态更新不重新读取图片。状态按账号保存到 App 持久目录，在线时每五分钟允许重新核对；离线显示最后已知状态，读取失败不伪装为未归档。

大图「更多」提供「归档所在聊天」，多选顶栏和菜单提供相同操作。批量操作先显示所选图片数量、去重后的聊天数量及影响说明，再逐个归档聊天；同聊天的所有图片同步更新，包括未选中的图片。已归档聊天跳过，停止只阻止后续聊天；成功项目取消选择，失败、缺少聊天信息和未处理项目继续选中。登录失效、限流或结果不确定时暂停，重试前先读取官网状态，避免重复写入。

归档改变 ChatGPT 的聊天状态，图片继续留在图库，收藏、隐藏与原图文件保留。全量扫描不会仅因已确认归档聊天的图片缺席而将其标成来源删除。本次仅支持归档，恢复聊天请在 ChatGPT 设置中操作。此功能依赖官网内部接口；接口变化或原聊天无法访问时明确提示，不猜测状态。

官网 Recents 与归档字段可能暂时不同步：实测曾出现详情已归档而未归档列表仍包含该聊天，官网原生 Archive 也能复现。随后重新加载整页、核对完整列表，48 个聊天均已移除。现有状态标记依据归档字段，不能保证侧栏立即更新；详见 [验收记录](docs/verification.md)。

卡片悬停或键盘聚焦时可以隐藏图片，大图「更多」也提供相同操作。隐藏状态只保存按账号隔离的图片 ID，不复制图片、不额外固定缓存；缓存模式与收藏规则继续生效。隐藏图片仅在「隐藏」中显示，隐藏的收藏不会出现在「收藏」，取消隐藏后仍保留收藏状态。在正常大图视图中隐藏当前图片，会立即切到相邻可见图片；最后一张移除后显示空状态。隐藏与取消隐藏使用约 200 ms 的淡出和布局移动动画，只处理已挂载卡片，并尊重系统减少动态效果设置。

收藏卡片和收藏的大图「更多」提供「在全部图片中定位」：切到全部图片的 grid 图库并滚动至该图片，同时保留收藏的原浏览位置。隐藏栏目不提供定位按钮；来源已删除但原图已保存在本地的收藏仍可定位。

大图「更多」中的「复制 prompt」按需读取原聊天，匹配该图片生成消息所在分支最近的用户原文。修改图片复制当次修改指令，重新生成复制原请求；同次生成的多张图片共享用户原文，不包含参考图片或整个聊天上下文。匹配失败时提示打开原聊天，不复制图片标题或其他分支的文字。只在当前图片库会话内缓存匹配文本，不将 prompt 或整段聊天写入本地数据库。Safari 一次点击可等待聊天请求后复制；浏览器拒绝复制时提示重试，API 不可用时提供可选文字手动复制。

查看器恢复轻量悬浮控件：左上角返回 grid 图库和开关缩略图栏，右上角缩放百分比、收藏、Describe edits 和更多，上一张 / 下一张位于画布两侧。按钮约 32 px，图片使用完整画布。菜单、编辑条、Toast 和控件显隐都不改变图片尺寸、倍率或查看中心；图片铺满时允许控件轻度覆盖边缘。

普通按钮、标题和切图箭头只在鼠标位置实际变化时显示，鼠标静止 2 秒后隐藏，即使停在按钮上或按钮仍有焦点。图片浏览时用左右方向键切图会立即隐藏控件，图片加载、后台刷新、Toast 和其他按键不会重新显示。打开的菜单、聚焦或有草稿的输入条保持可用，左侧缩略图栏由手动开关控制。

点击编辑按钮，在按钮下方展开独立的单行「Describe edits」，约 300 × 38 px，长文本和换行在框内滚动。Enter 提交，Shift+Enter 换行。聚焦或有草稿时保持展开；空白且未聚焦时闲置收起。手动关闭和切图会收起输入框，重新展开恢复对应图片的会话草稿，成功提交后收起，失败时保留。刷新列表不会清除草稿，关闭图片库不保存草稿。

「更多」和缩放采用本地打包的 Radix Dropdown Menu。悬停约 100 ms 展开子菜单，上级始终保留；跨间隙和斜向进入由组件的指针保护处理。宽窗口子菜单按空间向左或右展开，窄窗口上下排列并分别滚动。菜单方向键操作菜单，输入框方向键操作文本，不触发图片切换。图片详情与图片库操作为子菜单，缓存设置和快捷键说明嵌入子菜单；prompt 手动复制使用紧凑浮层。点击外部或 Escape 关闭。Toast 直接显示文字，在屏幕顶部水平居中，随内容收缩，长内容限制宽度。

提交前检查官网的新会话函数、对应状态、模型及路由；兼容已验证的两种导出布局。官网接口不匹配时明确提示并保留草稿，不调用旧导出或发送编辑。只读验证同时检查提交准备，不再只检查原图匹配。

提交后打开独立 Safari 窗口，在官网重新确认账号并按文件与消息标识匹配原图，调用官网的图片编辑、会话创建和结果导航流程。原聊天保留，生成结果在新窗口查看。源图片已删除或无法精确匹配时不提交，草稿保留；提交结果不确定时提示先检查新窗口，不自动重复发送。此功能使用现有 ChatGPT 图片生成额度，并依赖官网当前发布的内部前端接口；官网变化后可能需要更新扩展。

grid 图库和左侧缩略图列表均只挂载屏幕附近的卡片。最近看过的缩略图保留在共享内存缓存中，回滚和从大图返回时直接复用已解码的图片元素；内存预算为 256 MB，按图片字节和解码像素估算，优先回收较久未用的资源。这个预算不限制磁盘缓存。

大图另有 128 MB 会话内存预算，复用已校验的原图文件、Object URL 和已解码图片元素。返回 grid 图库后保留刚看过的图片，切图后预读前后一张已保存的原图；新增预读不联网。超预算时先回收较久未用的解码资源，再回收文件，当前或刚离开的图片保留；单张超大图可超过预算。刷新列表继续复用，切换账号或关闭图片库页面时释放，App 持久原图不删除。

首次从 App 读取原图时，元数据和首块一起返回，每块最多 4 MiB；常见大小的原图只需一次通信，仍核对偏移、总大小和完整 SHA-256。前台原图读取优先于排队中的后台任务；原生服务中断时先完成连接恢复，数据写入及其重试保持顺序。正常内存命中直接显示，不闪出加载提示；未保存的图片仍需要下载。

本地缓存直接读取，和联网下载分开调度；屏幕内图片优先，附近区域只预读本地图片。原图已缓存时，缩略图根据显示尺寸和屏幕像素密度生成，小 / 中 / 大切换会补足所需像素。旧的模糊或过大的缩略图自动从本地原图重建，不透明图片采用高质量 JPEG，透明图片保留 PNG；原图不改动。已知图片尺寸会保存，减少首次显示时的瀑布流重排。切换尺寸、刷新新增图片和窗口宽度变化时保留浏览定位。

## 自动缓存

默认「全量缓存」自动补齐官网可枚举的所有图片和后续新增图片，包含隐藏图片。选择「按需缓存」后，grid 图库中实际可见约 300 ms 的图片加入原图下载队列，快速掠过和屏幕外预加载卡片不触发原图下载。已入队图片离开屏幕后仍保留任务，新可见图片优先；缩略图与当前大图优先，邻图仍可预载。收藏会尝试保存完整原图。

两种模式只改变下载时机。原图没有应用层容量上限，不按图片日期、取消收藏或切换模式自动清理。缓存设置提供暂停、继续和失败重试；暂停后台缓存时，主动打开大图仍可以加载。全量切到按需后停止后续全量任务，保留已保存图片和按需任务。空间不足时暂停，保留已有原图。

进度按完整原图统计「已缓存 N / 总计 M 张（含隐藏）」。总数是当前账号官网图片数量，包含隐藏；扫描未结束时注明总数仍在增加，不把失败说成完成。按需模式不将未浏览图片称为待缓存。官网图片消失后，已保存原图继续本地可查看并标记「来源已删除」，收藏和隐藏仍有效；不计入官网进度，在设置中单列「本地保留 N 张」。原聊天、prompt 和 Describe edits 可能因来源删除而不可用。

关闭图片库后后台继续尝试缓存，App 窗口可以关闭。Safari 可能暂停后台，因此不能保证持续下载；每分钟唤醒、重新打开图片库或 Safari 启动会尝试恢复。Safari 完全退出后暂停下载，重开后续传。没有来源页面时自动打开后台 ChatGPT 图片库页；退出 ChatGPT 后暂停联网操作，本地图片仍可查看。

## 持久存储与迁移

App 与 Safari 原生扩展将原图、图片索引、收藏、隐藏 ID、缓存进度和查看状态保存到共享容器的 `Library/Application Support/ImagesManager`，按 Safari profile 和账号隔离。原生层从本地原图生成清晰缩略图，通过有大小限制的分块读取保存到 Safari IndexedDB，避免为显示缩略图传输整张原图。原生 `Caches`、Safari 缩略图和受预算管理的解码内存均可重建。本次不提供局域网共享。

迁移先复制，再按大小和 SHA-256 核对；可以中断续传。核对完成前不清理旧原图；核对完成后仍由用户明确操作「清理旧存储…」。同一签名身份的 IndexedDB 可以直接迁移。更换签名团队时 Safari 会隔离旧存储，空数据库不代表旧库迁移完成，需要使用临时旧存储导出工具：

1. 用旧签名身份构建并运行导出工具，在 Safari 点「复制并核对旧存储」。工具仅只读访问旧库，不下载、不刷新、不改变收藏与隐藏。
2. 导出完成后，用导出 App 的「存储 → 打开旧存储导出目录…」找到 profiles 目录。只保留一个签名版本注册在 Safari，切回固定团队的新 App。
3. 新 App 的「存储 → 导入旧存储…」通过系统目录选择器读取导出目录，复制并核对原图；已有收藏与隐藏状态合并保留。失败后重新选择同一目录续传。
4. 刷新图片库查看迁移状态。旧 IndexedDB 和导出副本仍保留；清理不是迁移成功后的自动步骤。跨签名版本的「清理旧存储…」先导出核对凭据，由用户在旧工具选择该文件并点击清理，仅移除核对过的旧原图副本，索引、收藏、隐藏和导出副本保留。

共享容器降低了对 Safari 存储的依赖，仍需自行备份重要图片。它不提供永久保存保证，也不会在磁盘不足时自动删除原图。

## 开发与构建

需要 Node.js、Xcode、XcodeBuildMCP CLI 和可用的 Apple Development 签名身份。先复制 `.local-signing.example.json` 为 `.local-signing.json`，填写固定团队 ID 与证书 SHA-1；可用 `rtk proxy security find-identity -v -p codesigning` 在本机查找。实际签名配置被 Git 忽略，不提交到公开仓库。两个目标必须用同一团队，构建不自动注册开发者门户资源。React 与 Radix 用于菜单界面，随扩展本地打包；其他依赖用于打包与测试，扩展运行不依赖第三方服务。

rtk proxy npm ci
rtk proxy npm run check

## 数据与验证

原图、索引、收藏、隐藏 ID 和进度保存在 App 管理的持久目录，缩略图保存在 Safari 扩展 IndexedDB，账号隔离。登录凭据不写入图片缓存，不发送到其他服务。读取图库的凭据仅在 ChatGPT 页面的隔离脚本中短暂使用；Describe edits 通过 `scripting` 在官网页面环境调用其现有服务，不向扩展返回凭据。扩展网站权限只包含 `https://chatgpt.com/*`，不新增其他网站。

ChatGPT 的网站接口不是公开稳定 API；数据结构或分页异常时保留原有记录，不把失败误判为图片删除。当前实现按网站实际发布模块中的 `after` 游标分页。自动化测试覆盖两种缓存模式、可见停留、下载优先级、统计口径、状态隔离、队列恢复、重复分页、空间不足、并发收藏，以及原生分块、重复提交、导入续传和损坏数据保护。真实 Safari 验证结果见 `docs/verification.md`。

菜单源代码位于 `ui/viewer-menu.jsx`，样式位于 `extension/floating-controls.css` 和 `extension/viewer-menu.css`。`npm run preview` 与 `npm run safari` 自动执行 UI 打包，也可以运行 `rtk proxy npm run build:ui`。生成的 `extension/viewer-menu.js` 和第三方许可证清单不手工编辑。

启动本地预览后，用 `rtk proxy npm run test:viewer` 运行菜单交互回归；需要 agent-browser CLI，脚本只在独立浏览器会话的 localhost 合成图片中运行。

`rtk proxy npm run test:grid` 验证多选、批量收藏与隐藏、停止、磁盘写入失败重试、虚拟滚动和窄窗口布局，也仅修改独立测试会话中的合成数据。

`rtk proxy npm run test:archive` 验证聊天去重、状态同步、筛选、确认、停止和失败重试，以及状态更新时原图片节点与资源保持复用；只修改独立 localhost 会话中的合成聊天状态。
